# Project_A_PreChange — Legacy integration

This project demonstrates the legacy service calling /api/v1/checkStock.

Quick run (Linux/macOS):

```bash
cd Project_A_PreChange
./run_tests.sh
```

Windows (PowerShell):

```powershell
python tests/test_pre_change.py
```

Outputs:
- results/results_pre.json — test results
- logs/log_pre.txt — console output
