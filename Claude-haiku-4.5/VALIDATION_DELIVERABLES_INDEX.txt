ISSUES FOUND AND RESOLVED
════════════════════════════════════════════════════════════════════════════════

1. Missing Log Directories
   Problem: Tests failed with FileNotFoundError
   Root Cause: log_pre.txt and log_post.txt paths didn't exist
   Resolution: Created logging directories and fixed path handling
   Impact: Tests now pass, logging functional

2. Fragile Logging Configuration
   Problem: Relative paths were unreliable from different working directories
   Root Cause: Using ../logs/log_file.txt from src directory
   Resolution: Changed to use Path(__file__) for absolute paths
   Impact: Cross-platform compatibility improved, robustness enhanced

3. Incorrect Fixture Parameter
   Problem: V2ApiClient initialization failing in tests
   Error: TypeError: unexpected keyword argument 'api_base_url'
   Root Cause: Test fixture using wrong parameter name
   Solution: Updated parameter name to 'base_url'
   Impact: All Project B tests now pass
